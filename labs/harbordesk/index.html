NETWORK SECURITY

Network services

Real service protocols within the local loopback test boundary.

Declared service inventory

Loaded from /__lab__/inventory. A declared mode is configuration, not a scanner result or proof that a listener is reachable.

FTP comparison

Loopback port 2121 permits anonymous FTP in the vulnerable configuration. Port 2122 provides the authentication comparison. Both use plaintext transport.

Use an FTP client or a protocol-aware assessment. Browser HTTP navigation does not test FTP authentication.

TLS management comparison

Loopback port 8443 uses an expired certificate and unauthenticated management. Port 8444 provides a certificate within its validity period and an authenticated comparison.

The comparison certificate is self-signed; validity dates do not establish browser trust. Inventory alone does not validate TLS or access controls.

Scope: this computer only. These are local test services, not internet targets. Start the backend with --network to enable the listeners. Disabled inventory does not indicate a scan failure.
